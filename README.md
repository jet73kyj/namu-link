# 나무링크 함수 원문 보관

## 왜 있나
함수를 고칠 때 글자를 찾아 바꾸는 방식(replace)을 쓰면
- 글자가 조금만 달라도 못 찾고
- 고칠 때마다 원본이 무엇이었는지 알 수 없어지고
- 되돌리기 어렵습니다.

그래서 함수 원문을 여기에 파일로 둡니다.

## 고치는 순서
1. 이 폴더의 .sql 파일을 고친다
2. 그 파일 내용을 통째로 복사해 Supabase SQL Editor 에 붙여넣고 Run
3. 한 아동으로 시험해 확인
4. 잘 되면 그대로 두고, 안 되면 git 으로 이 파일을 되돌린 뒤 다시 붙여넣기

## 파일 목록
- nl_make_sessions.sql — 그 달 전체 회기 깔기
- nl_remake_schedule_month.sql — 요일줄 하나만 다시 깔기
